## 🔍 6. Slots para Platos en Modal Quick-View (Opcional)

Si más adelante deseas agregar fotos individuales para platos específicos, el modal de Quick-View ya está preparado para recibirlas en:
- `/public/images/carta/[macro]/[nombre-plato].jpg` (ej. `/public/images/carta/salados/lomo-saltado.jpg`, `/public/images/carta/desayunos/huachano.jpg`, etc.)
- Dimensión recomendada: `800x600px` (4:3).
- Si la imagen aún no existe o el archivo no se encuentra, el sistema muestra automáticamente el placeholder editorial con el isotipo Lynch.
